# 📒 Contact Book

A simple and efficient contact management application built with Python.  
This project helps users manage their contacts by adding, viewing, searching, updating, and deleting contact information.

## ✨ Features

- ➕ Add new contacts
- 📋 View all contacts
- 🔍 Search contacts
- ✏️ Update contact information
- 🗑️ Delete contacts
- 💾 Save and manage contact data
- ⚡ Simple and user-friendly interface

## 🛠️ Technologies Used

- Python 🐍

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/manikermanii/contact_list.git
```

Navigate to the project folder:

```bash
cd contact_list
```

Run the application:

```bash
python main.py
```

## 📖 How to Use

1. Run the application.
2. Select an option from the menu.
3. Add new contacts.
4. Search for existing contacts.
5. Edit or delete contacts when needed.
